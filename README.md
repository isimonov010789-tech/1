# Character studio video

Проект для одного персонажа на белом фоне: **1080×1920, 24 fps, 8 секунд (192 кадра)**.

Включён **превью-ролик из неподвижного изображения с плавным приближением на 4%**. Моргание, дыхание и мимика в нём не сгенерированы. Remotion и HyperFrames собирают композицию, а реалистичное движение нужно получить отдельно через image-to-video.

## Remotion

Node.js 22+ и npm:

```bash
npm ci
npm start
npm run typecheck
npm run build
npm run render
```

Композиция сохраняет ID `TeacherVideo`, чтобы существующая команда экспорта продолжала работать. Результат — `out/teacher-video.mp4`.

## Подключение живого видео

1. Используйте `public/character-front.jpg` как исходный кадр и `prompts/image-to-video.txt` как промпт.
2. Сохраните готовый клип длительностью не менее 8 секунд в `public/character-motion.mp4`.
3. Экспортируйте:

```bash
npx remotion render src/index.ts TeacherVideo out/character-motion.mp4 --props='{"videoSrc":"character-motion.mp4"}'
```

Этот режим использует готовый клип без дополнительного увеличения; звук отключён. В Studio можно изменить `videoSrc` через параметры композиции.

## HyperFrames

`hyperframes/index.html` содержит эквивалентное превью с тем же кадрированием и масштабированием. Открывайте его через HyperFrames Studio/CLI; обычное открытие HTML показывает начальный кадр, поскольку воспроизведением управляет HyperFrames. При экспорте задайте 24 fps.

## Исходники

- `public/character-front.jpg` — первый фронтальный ракурс согласованного листа персонажа, без остальных фигур.
- `src/TeacherVideo.tsx` — превью и подключение готового клипа.
- `src/Root.tsx` — размер, частота и длительность.
- `prompts/image-to-video.txt` — согласованный промпт.
- `DESIGN.md` — внешность и ограничения визуального оформления.

Исходный ракурс имеет ограниченное разрешение: экспорт 1080×1920 не добавляет новых деталей лица.
